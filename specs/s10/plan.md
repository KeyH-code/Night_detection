## 计划

- **输入：**终评与工程结果、有效代码/配置、权重及数据/实验索引。
- **任务：**让第三方可以定位数据、初始化、训练决策、有效参数、日志、权重和结论；核对版本/哈希、命令说明、路径及许可，清理本轮临时残留。
- **产物：**维护后的README、计划状态、规则、结构和正式报告；原始证据只保留一份。代码、权重和展示素材分别核验发布边界，Git提交/推送或公开发布按实际授权执行。
- **通过：**结论不超出证据；跨数据集只作带条件的数值参照，不能据此证明样本效率相同；Agent验证不冒充用户独立实践证据。
- **失败：**缺配置/身份/记录时明确不能复查的范围，不重建虚假历史，不为“证明做过”保留垃圾。

## 公开数字复算

- 从已封存的白天源模型、300 图主方案和 340 图定向补样的开发预测导出指标输入。只保留 AP 所需的排序匹配标记、工作点所需的聚合计数、样本数量与来源哈希。
- 提供 CPU 复算命令。数据和依赖齐全的干净副本上，须算出 README 的白天保护、三类夜间恢复与两类剩余缺口，并校验来源包完整性。README 说明复算、模型推理和训练回归各自的输入及边界。
- 本地候选先验收。权重、原图、原始标注和冻结划分索引继续按各自的分发条件管理。
- **本地验证通过。** 干净副本按数据依赖锁复算成功，38 项数据与完整性回归、166 项训练与诊断回归通过，CPU 单图示例正常生成结果。验收覆盖开发集数字的聚合复算，原图推理重放和真实训练留待相应输入就绪。


## 原图开发集评估

- 从用户自行获取的官方 train/val 和冻结哈希索引重建开发图片及标签。代码核对 checkpoint 与依赖版本，复用原多视图推理及五类指标。
- 核对 300 图主方案的白天保护和夜间恢复，提供可选的 340 图尾类复查。输出带输入身份、指标和归档差异的独立 JSON。训练及最终留出保留各自范围。
- **本地验证。** 干净副本核对 831 张指标开发图、重建后的标签和三个 checkpoint 哈希通过，40 项数据与复查回归通过。主方案及补样的摘要比对用封存指标校验，v0.1.0 发布前已在本机 CUDA 从原图重跑白天源模型、300 图方案的昼夜评价和 340 图定向补样的夜间评价。README 指标按显示精度吻合，夜间 TP、FP 和真值数逐类一致。


## 开发集数据包

候选包含白天 500 张、夜间 331 张 JPEG 及其原冻结 YOLO 标签，随 Release 提供 ZIP 与 SHA-256。只发布复查开发集指标所需的文件。ZIP 路线逐项比对既有索引，与官方原图重建路线共用 CUDA 评价及输出。候选先在本地完成审核。

干净副本的 CPU 输入核验与 43 项回归通过。ZIP 路线使用三份发布权重重跑 CUDA 评估，白天及夜间摘要与官方数据目录路线一致。代码提交与 ZIP 留待发布前审核。
