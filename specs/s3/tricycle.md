# 三轮车

## 范围

以锁定的 [`scale_004 / a1`](scale.md#候选锁定) 为唯一对照，先在完整白天 `source_dev` 改善三轮车，并保住已达标五类。三轮车资格、五类保护和证据精度不改，统一从 [RULES.md](../../RULES.md) 读取。固定检测器权重，只改变三轮车输出；如需加入重排器，必须同一配方与同一检测器一起确定身份，不按类拼不同 detector checkpoint。候选达到数值门槛也只称开发结果。禁止读取留出集及夜间标签，不改写冻结目录与 `scale_004`。

共同记录：三轮车 AP50/AP75/AP50:95、Precision 约束下的 Recall 和误报、22 个 GT 的匹配迁移、2000 次风险组区间。将其余五类框、分数、工作点和门槛逐项和 `scale_004` 核对，合并上限仍为 300（五类先保留）。若当前配方不达标，先用输出区分是定位覆盖不够，还是可用框的排序/误报不够，避免盲目扩训。临时实现和预测放 `D:\Temp`；实际形成可复查证据后归 `runs/`，结论归源模型报告。

离线诊断确认 15 个漏检中 14 个有贴合解码框，其中 11 个三轮车分数低于工作点、3 个低于输出地板。放宽到至少找回 11 人的最佳精度只有 64.71%（11 TP / 6 FP）；不能仅靠降阈值。原尺度重排使用 `source_train` 存档、按风险组哈希预留 25% 组作内验证，以原分数 logit 加可学习残差，分别比较线性/小 MLP 与二元/IoU 质量监督。预选指标 `AP50:95 + 0.30×受约束 Recall`，内验证严格 AP 至少改善 0.5 个百分点且召回回退不超过 3 个百分点才将排名第一的配方送入开发集；内验证门是筛查，不替代正式验收。先输出 25/50/100 步的比较，禁止用 `source_dev` 选步或参与拟合。

## 低尺度补视图

首轮 `512+640+800` 原图共识达到 12 TP/2 FP，严格 AP 已过线，但 AP50 距门槛约 2.10 个百分点。960 单视图只检出 4 个，故不再加大输入。该三视图在原工作点的 12 个真检出与 AP50 的对应匹配一致，不优先调 NMS。追加三个独立对照：①加 448 原图，测试更粗尺度的覆盖；②加 576 原图，测试低尺度间连续采样；③将三个原图视图各配一个镜像，测试方向一致性（只需新增 512 镜像，640/800 镜像复用）。三个对照固定用相同融合参数，比较共识与最高分并集，不网格调参。**云端 GPU 预算 0 小时／0 元**；本机只补三次完整开发集前向。如多个对照同过线，选择新增前向更少且有指标余量者；未过线则先比较失误迁移及分数，不为了补点数修改三轮车标注。

### 粗尺度确认

448 原图加入以后 AP50 升到 59.33%，仍差 0.67 个百分点；576 和低尺度镜像没有同向改善。448 组合在 12 个工作点真框上未出现 AP 匹配挤占，较高分误报主要与冻结标注的骑行者或卡车重合，单项强混淆规则也可能误删真三轮车。暂不调类别权重/阈值，追加两档原图粗尺度 384、416，分别作为唯一新增视图与 `448+512+640+800` 对照，保持共识参数和其他类别不变。只做这两档，由视图增量评估收益；**云端 GPU 预算 0 小时／0 元**，新增两次本机完整开发集前向。

平行离线对照：在同一个 448 组合上，仅用预测做轻量类别竞争降分。若与锁定 640 的骑行者或卡车框 IoU≥0.75，以该重叠类最大分数 `s` 乘上系数 `1−0.25s`（无重叠系数为 1）。这针对高分误报的实际重叠模式，不硬删候选、不读标签决定分数，也不修改其他类。固定只比较这一规则和原 448 组合，不搜索权重；**云端 GPU 预算 0 小时／0 元**，无新前向或梯度。

### 固定候选的取框和排序

416 组合找回 13 个、AP50 59.58%，但 AP75 从 448 组合的 51.60% 降至 45.13%；粗尺度引入的框会改变融合坐标。类别竞争降分未改善，暂不再改跨类分数。固定同一批 416 组合和同一聚类，比较两个单因素改动：①平均置信度不变，取簇内与其他框加权 IoU 最高的真实框或最高分框，检查平均是否拉松了框；②保留加权框，只将置信度从算术均值改为平方均值开方，检验算术均值是否压低个别高质量视图，缺失视图仍为 0。先验证旧聚类可逐项重放，再用完整开发集比较，采用方式不得读取真值。**云端 GPU 预算 0 小时／0 元**，全部离线，不再追加视图。

平方均值开方的未舍入 AP50 为 `0.599889601501207`，不能四舍五入宣布过线。另做一个仅改变分数聚合的离线对照：用算术均值与 RMS 的等权平均保留两者证据，另列 `1−∏(1−s)` 为多次分数的有界并集排序，不解释为视图独立的校准概率。继续固定同一组候选和加权框，不搜索参数。**云端 GPU 预算 0 小时／0 元**。

## 原图复现

有界并集排序是首个达到全部开发数值门槛的探索方案，登记 `low416-or` 为复现配方。由 [`tricycle_fusion.py`](../../scripts/tricycle_fusion.py) 重新验 `a_001 best` 和 `scale_004`，从完整 500 张原图重跑 416／448／512／640／800，再只替换锁定三轮车分支；已达标五类逐框、分数和工作点复核，输出 2000 次风险组区间。与原探索输出逐项对齐后保存 `runs/tricycle_001/`，不覆盖锁定对照。**云端 GPU 预算 0 小时／0 元**；复现不改变白天正式单路 640 口径。

```powershell
.\.venv-train\Scripts\python.exe -B -u scripts/tricycle_fusion.py --profile low416-or --scratch D:\Temp --output runs/<新实验目录>
```
