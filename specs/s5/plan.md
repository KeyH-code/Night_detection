## 恢复目标

**已确认的项目主目标：**每个方法、每个种子最多使用 **100 张不同的额外夜间训练图**。在同一 `FPPI ≤ 0.1` 的误报预算和同一推理、匹配口径下，适配后的夜间**行人、汽车召回分别至少达到同一冻结 A 白天对应召回的 80%**；不允许两类互相抵消。80% 是白天表现的比例，不是绝对召回 80%，也不是填平 80% 的昼夜差距。其他三类仍报告，不计入这一主目标。该目标已确认，不代表已经达成或证明百图足够。

- **白天分母：**冻结 `align_001/17/last.pt` 在完整 `source_dev` 的同口径逐类召回。先从封存的白天预测离线复算并固定，不使用报告里的逐类 Precision 工作点，也不以适配后的白天结果替换。每类夜间目标值为对应白天召回 × `0.80`，用未舍入数判定；若白天参照缺类、分母为 0 或证据不足，标记该类不可判定并复核。
- **夜间衡量：**S5 用固定 A 先测 `night_dev` 零样本水平；S6 各臂、各 seed 报告两类召回、达到白天参照的比例、离目标的差值，以及相对零样本的变化。若零样本已过某一类，不将原有能力归功于新增夜间图。逐类逐种子保留结果与区间，整体通过采用何种重复判据在 S6 正式实验前登记，不选最好种子替代全部结果。
- **另作两个判断：**策略对随机的配对差判断**选样有没有额外收益**，白天保护判断**适配是否损害白天能力**。两臂都可达到恢复目标，即使未证明策略优于随机；策略也可能优于随机但仍未达恢复目标。S5 不判定适配成败，开发成绩不当作留出终评。

## 一、协议评审

主档、辅助档、工作点、推理及报告口径、证据与停止条件已确认，先于 `night_dev` 测量。首批将已确认的评价参数写入 `configs/night.json`，由脚本及 run 用其哈希绑定；选样参数及 S6 对照验收草案仍待各自阶段锁定。白天 [RULES.md](../../RULES.md#夜间) 本身已被 `align_001` 的验收清单按整文件哈希封存，不改正文来登记夜间门槛，否则现有白天复算会拒绝。

| 决策 | 口径 |
|---|---|
| 主档及读数 | 恢复目标采用 `FPPI ≤ 0.1` 的逐类召回；选样收益对照拟用主档的两类等权宏平均召回，`≤0.5` 辅助报告。FPPI = 两主类误报框之和 / 全部图数，空标注、无主类图片也进分母。主档在 500 张白天开发图允许 50 个误报框、在 331 张夜间开发图允许 33 个。不因结果难看或区间宽而事后调换主次。 |
| 工作点 | 白天参照和每个模型/种子的夜间开发结果使用相同公式，分别在各自开发集选一个**两主类共享**阈值；同一误报预算不等于同一置信度数值。遍历完整未舍入分数事件，同分整批进入；每档先筛框，再做同类 IoU≥0.5 一对一重匹配。在误报预算内最大化宏召回，同召回取误报少、再取阈值高；允许明确记录的空输出点。报告实际 FPPI 和计数；留出测试只迁移已锁阈值，不能重选。 |
| 推理与报告 | 评价沿用 S4 五类输出：同权重 640 原向输出四个非行人类，行人用 960/1280 原向与镜向四路融合，保持原置信度地板、类内 NMS 和上限顺序。每类报告 AP50/AP75/AP50:95、支持量及两档阈值下 P/R、TP/FP/FN；辅助类不进主类 FPPI 或宏召回。无真值的类在对应指标标 N/A，不记零分。 |
| 证据与停止 | 按冻结风险组做 2,000 次重采样，配对比较用同一组抽样，区间内固定各模型阈值；抽到缺任一主类的重复记无效并报告数量，不把风险组当作官方独立序列。建议主终点 95% 区间总宽目标为 20 个百分点。任一主类无支持、主点宏召回为零、无法计算区间或区间过宽则停在复核门；NMS 超时使本次采集无效，输出达到上限须报告并复核是否影响解释。不因这些问题自动换主终点、改上限或扩大训练。 |
| S6 成效与白天保护 | 草案：17/29/43 三组策略减随机的主点召回差都为正、均值至少 +3 个百分点；两档两臂实测 FPPI 的绝对差分别不超过 0.02/0.05。适配臂对冻结 A 的白天同口径行人、汽车 AP50:95 各回退不超过 2 个百分点，另报告三辅助类及小/细行人 AP75、召回切片。报配对区间；跨零只称证据未定，不据此自动扩展。固定共同 A 的三次配对不证明跨源初始化稳定性。 |

**检查点：**首批以合成回归为门，不读取真实夜间数据。若日后改变已确认的指标、推理或数据，需另行审批、记录原因和新身份；旧结果保留为开发证据，不能混进同一预登记批次。

## 三、白天参照与夜间基线

1. **先授权，再离线复算白天参照。** 评价代码与回归通过，锁定协议后，核对 `runs/align_001/17/dev/objects.jsonl.gz` 的封存 SHA、500 个白天开发 key 及 A 的身份，用共同评价器复算工作点、逐类召回、区间和恢复目标值。保存参照及其输入/协议 SHA，不重跑白天模型，不回写历史结果。
2. **再获准测完整夜间基线。** 确认本机设备、磁盘和锁环境匹配，输入只含 `night_dev`。先用同口径小批预检读取和显存耗时，阈值不从小批估计；再用 A 无梯度推理完整 331 图，核对 key 唯一且齐全。设备繁忙、OOM、身份不符或版本不符则停，不静默改分辨率、精度或转云。
3. **封存两边并复算。** 从逐图输出离线重汇总工作点、计数、AP、支持量和区间，报告日夜差、零样本离恢复目标的差值、运行开销及样本限制。在 `runs/night_<编号>/` 保存 `run.json`、`metrics.json`、白天参照、必要夜间对象/匹配/曲线及 `manifest.json`，绑定权重、清单、配置、代码、环境和实际参数，不复制已有白天预测、原图或权重。有效结果形成后才在 `reports/night.md` 写结论。
4. **复核是否继续。** 检查白天分母有效、夜间主点有可用信号及支持量。基线低不等于实验失败；无可比较工作点、身份/数据不一致或证据不足则先复核，不因想推进 S6 而放松协议或访问留出。

## 四、百图选样与交接

以下选样参数也需在正式池推理前锁定。它是简化的一致性/多样性选样，不宣称完整复现 CALD。

- **不一致分（640 同一 A）：**原图、两种 Gamma（输入归一化后 `x^0.7` / `x^1.5`）和水平翻转，共四次预测。将框映回原图；仅用五类且分数大于 `0.05` 的框。对原图与各变换按 IoU≥0.5 由高到低做不看类别的一对一匹配，确定性处理并列。已配框取 `(1−IoU + 类别改变指示值 + 绝对分差)/3`，未配框用其置信度；每对视图按框事件平均，两侧均空记 0，再对三种变换等权平均。这样能同时计入位置、类别、置信度和漏匹配，不用任何标签。
- **随机与多样性：**每个 seed（17/29/43）对稳定顺序的候选 key 做可复算的均匀无放回排列（NumPy PCG64）；随机臂取前 100 张，策略臂共用前 20 张作为随机覆盖，且不强制禁止其余自然重合。其余 80 张从排除这 20 张后的不一致分前 320 张里挑：使用原图预测同次采集的末级骨干特征做全局平均池化和 L2 归一化，先锁定层身份；以 20 张为起点，每步取到已选集合最小余弦距离最大的候选，并列优先不一致分、再按 key。特征非有限或零范数、候选不足或分数无区分时停并审查，不临时换排序或看 GT。
- **正式池消费与封存：**通过隔离回归且单独获准后，才在仅图沙箱对全部 994 张采集；在 `runs/pool_<编号>/` 保存处理身份、复算所需的不一致分与归一化特征、按 seed 的名单、重合/风险组覆盖及 SHA 清单。报告重复性和覆盖，不用 `night_dev` 表现选名单，更不读取候选 GT。训练准备是分开的授权与入口，先验证名单哈希，再以只含所选并集的标签回执校验 GT 来源与哈希；未入名单、dev、test 一律不得进入梯度数据。
- **S6 共同配方：**D/E 共用冻结 A、相同有效 batch、优化器及学习率、增强、更新数和固定末轮 EMA，拟用同一 seed 的白天回放流，各有效 batch 内白天与夜间图槽位 1:1。A+ 匹配总更新，仅用白天并记录曝光差。保留原六类头及原标注语义，不把未评三轮车改标或当背景。S5 交接前确认配方及上限，记录批量 `B`（偶数）、更新上限 `T`、每臂的实际数据流与预期每域 `T×B/2` 图槽位、夜间 100 张的重复策略、学习率日程及增强，不能沿用 S3 默认值；不运行真实梯度。S6 受控预检才核验可行性、实际槽位与开销；需要变更则重审配方，不静默降批或追加训练。
