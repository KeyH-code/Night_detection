## 二、官方声明的范围

[论文第 3.3 节](https://arxiv.org/html/2106.11118v3) 列出 5K train、5K val、10K test，并说明三个官方集合的 sequence 互斥，同 sequence 为同车同日。train 的集中场景描述与本地元数据一致；val 本来就包含昼夜等多个场景。

[官方下载页](https://soda-2d.github.io/download.html) 分别列出 Trainval、Test 和无标注集。首版只用 Trainval；未下载 Test 是计划范围，不是当前 Trainval 缺少一部分。约 5.6 GB 的页面介绍不足以单独判定某一包缺失，应结合入口、包内容与图片清单核验。

[官方格式说明](https://soda-2d.github.io/documentation.html) 公布的图片字段正是本地实际的八个字段，未承诺包含 sequence/car/day 映射。原始集合隔离声明与公开 JSON 不带重划分映射可以同时成立。**此前“正式划分缺少采集组依据”是本项目额外内部划分的可行性问题，不能直接说成下载缺件或官方隔离失效。**

已查[官方站点仓库](https://github.com/soda-2d/soda-2d.github.io) 完整文件树（主分支 SHA `e89086b179d508c7eca705086d95c5a568bc4ba0`）和公开 issues：未见独立采集组映射、修正版 COCO 标注或补丁发布指引；issues 返回空列表。也搜索了公开资料中的 sequence、标注与 trainval 下载线索，未找到可验证的额外官方分组文件。这是已查范围内的结果，不声称其他渠道一定没有映射。

对齐依据为 HTTPS 内容、完整本地校验与远端抽样，不包含发布者签名。官方数据的语义质量尚需人工审核，不能以官方来源替代正确性验证。

## 三、人工审核入口

原始 val JSON 本身把 `HT_VAL_003746_GZ_231.jpg` 等图片标为 Night；同包原图在 Agent 初审中被认为有偏白天外观疑点，具体时段仍待核对。来源问题已排除到上述证据范围，标签疑点可基于原图审核，当前没有自动改标。

感知哈希 1,324 条候选边形成 320 个连通组。网页保留每条边的距离，不把传递连接解释成任意两图都相似，也不把候选组视为可靠 sequence。

本机网页：[http://127.0.0.1:8731](http://127.0.0.1:8731)。三个视图：

- 来源与划分：核验依据及官方声明范围。
- 夜间属性：固定种子按城市×道路类型抽 24 张覆盖样本、15 张 Agent 初审疑点、24 张高亮候选、全部 1,656 张 Night 和白天对照。
- 相似候选组：默认随机抽 12 组，可查看全部 320 组、按城市和图片 ID 检索、展开具体配对距离。

每图显示官方 split、ID、原文件名、原属性、原始路径和 SHA-256，可打开完整原图。图像读取时校验原审计哈希；缩略图仅用于本机显示，不改变原图。

判断保存在当前浏览器，支持单项撤销、JSON 导出；Agent 标记不会预填成用户结论。导出带数据指纹及图片哈希，不自动进入训练、改标或删除流程。审核前的功能测试判断已撤销。

用户随后提交的 24 张／12 组审核已单独记录于 [人工抽样结论](human_review_2026-10-25.md)。5 张被选择的样本属于可能阴天或暮光的边界疑点，不直接归为白天；相似组也未被用户确认是相邻帧。
